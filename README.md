# Prótesis izquierda de Adrián · manual de armado

Sitio estático (GitHub Pages) del equipo HAND-E: modelo 3D interactivo, qué es cada pieza, material y medidas,
cómo se une el socket con el antebrazo, manual de armado paso a paso, capacidad estimada, recomendaciones y
descarga de cada pieza en STL (todas caben en una impresora de 22 cm; la más grande mide 158 mm).

- `index.html`, `app.js` — la página (three.js r128 local, sin servidor).
- `modelo.js` — mallas reducidas, catálogo, pasos y datos del mecanismo (generado por `scripts/48_sitio_manual.py`).
- `stl/` — cada pieza para imprimir, en milímetros, y un ZIP con todas.

Los escaneos se publican con permiso de Adrián. Las capacidades (agarre, carga, autonomía) son estimaciones de
cálculo, no pruebas.
